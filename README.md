## ✨ ¿Qué es 3D Lab?

Una referencia práctica para aprender a identificar, nombrar y aplicar geometrías CAD al diseñar piezas para fabricación aditiva. Busca una forma o concepto en español o inglés y consulta su esquema y las recomendaciones de impresión.

<div align="center">

**🔍 BUSCA → 📐 IDENTIFICA → 🛠️ DISEÑA → 🖨️ IMPRIME → 🧪 VALIDA**

</div>

| Recurso | Qué encontrarás |
| :--- | :--- |
| 📚 Catálogo visual | Once categorías de operaciones, bordes, agujeros, uniones, mecanismos y más. |
| 🔍 Buscador | Términos técnicos, sinónimos y equivalencias en español e inglés. |
| 📏 Medidas | Referencias de tornillería métrica, holguras, paredes y capas. |
| 🧩 Ajustes y agujeros | Gotas, hexágonos, ranuras elásticas, dobles pestañas, membranas sacrificiales y puentes perpendiculares. |
| 🧪 Calibración | Procedimiento para comparar geometrías y tolerancias mediante pruebas físicas. |
| 🌗 Apariencia | Modos claro y oscuro, interfaz adaptable y copia de nombres técnicos. |

> [!IMPORTANT]
> Las cotas y tolerancias son orientativas, no especificaciones certificadas. Verifica cada diseño con tu impresora, material, orientación y perfil de laminado. Los SVG son esquemas conceptuales, no planos de fabricación a escala.

## 🚀 Abrir el catálogo

**[goyoaga.github.io/3d-lab-recursos](https://goyoaga.github.io/3d-lab-recursos/)**

No requiere cuenta, instalación, servidor de aplicaciones ni base de datos. Para consultar la versión local, descarga el archivo y ábrelo en un navegador moderno; los visores de archivos de terceros pueden bloquear JavaScript.

## 🧰 Ejecutarlo en local

```bash
git clone https://github.com/goyoaga/3d-lab-recursos.git
cd 3d-lab-recursos
```

Abre `index.html` directamente en tu navegador. No necesitas Node.js ni instalar dependencias.

## 📦 Estructura y publicación

```text
3d-lab-recursos/
├── index.html    # Interfaz, estilos, catálogo SVG y lógica JavaScript
└── README.md     # Documentación del proyecto
```

El catálogo es una aplicación estática. GitHub Pages puede servirlo directamente desde la rama `main` y la carpeta raíz `/`, sin proceso de compilación.

## 🧠 Herramientas y aprendizaje

La biblioteca es independiente del programa CAD. Está orientada al aprendizaje con SolidCraft y a la fabricación FDM, y también resulta útil con Fusion, FreeCAD u otros programas de diseño paramétrico.

## 🤝 Sugerencias y mejoras

Si encuentras un error, quieres proponer otra geometría o compartir un resultado de calibración, puedes abrir una [issue](https://github.com/goyoaga/3d-lab-recursos/issues). Incluye el concepto, material, dimensiones y orientación de impresión cuando corresponda.

El catálogo es de acceso público. No se ha establecido todavía una licencia explícita de reutilización del código y los contenidos.
